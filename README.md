with the extraction done, i'll explain what the 2 python scripts are:
* **read.py** \[filename\]: read script. takes in optional filename, often a file with the **.mafs** extension. if omitted, it will read from **fs.mafs**.
* **write.py** (foldername) \[filename\]: write script. takes in required foldername, which is the name of the drive and optional filename, where the output is written. again, if omitted it will write to **fs.mafs**.
